# Budget mensile

Web app per registrare dal telefono le spese del mese: entrate previste, budget per categoria, residuo e storico dei mesi.

- **Installazione:** apri il sito dal telefono e aggiungilo alla schermata Home (Safari: Condividi → «Aggiungi alla schermata Home»; Chrome: ⋮ → «Aggiungi a schermata Home»).
- **Dati:** restano solo sul dispositivo (memoria locale del browser). Il repository contiene solo il codice dell'app, nessun dato personale.
- **Backup:** scheda Budget → «Salva backup» / «Importa backup». Export in Excel con «Esporta in Excel».
- **Offline:** dopo la prima apertura funziona anche senza connessione.
